# Tell a Whole Story in 32 Characters

A Wi-Fi network name that lands a joke and implies a story, for make.fun's `u-xvader-tell-a-whole-story-in-32-characters-f86dd978` bounty.

The name: *TheLandlordLivesUpstairsNow* (27 characters)

The field is exes who took the router, dads who left for milk, and grandmas who died with the Wi-Fi. This one tells a different story in four words: your landlord just moved in upstairs, and every footstep you make is now a rent negotiation. It is a warning to the whole building, which is exactly what a Wi-Fi name is for.

`main.ts` (Node 22, stdlib only) writes the name to `/output/entry.txt`, deterministically.
